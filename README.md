# Zhannur Bakyt
## SE-2524

## Assignment 5. JavaScript Basics

## Description
This project demonstrates the fundamentals of JavaScript, DOM manipulation, and event handling. It includes interactive tasks created using HTML, CSS, and JavaScript.

## Tasks
-Task0: First Script: Display information in the console and show an alert.\
-Task1: Variables & Operators: Work with variables, data types, arithmetic operations, and string concatenation.\
-Task2: Changing Content: Change paragraph text when a button is clicked.\
-Task3: Changing Styles: Change the background color and font size of a block.\
-Task4: Creating & Removing Elements: Add and remove list items dynamically.\
-Task5: Mouse Events: Change a box's color when the mouse enters and leaves it.\
-Task6: Keyboard Events: Display input text in real time using keyboard events.\
-Task7: Calculator: Perform addition, subtraction, multiplication, and division.\
-Task8: Interactive To-Do List: Add tasks, mark them as completed, and delete them.
